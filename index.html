Gunakan volume rendah agar fokus tetap terjaga. Pengaturanmu tersimpan di perangkat ini.

📖 Petunjuk Singkat

  1. Ketuk Lanjut → / ← Kembali untuk berpindah halaman (di komputer bisa pakai tombol panah).
  2. Ketuk subkulit atau tombol animasi untuk melihat penjelasan.
  3. Seret model 3D untuk memutarnya; tekan Reset posisi untuk mengembalikan.
  4. Jawab pertanyaan pemantik agar tombol Lanjut → terbuka.
  5. Kerjakan eksplorasi, lalu tekan Periksa jawaban.
  6. Atur musik, efek suara, dan narasi suara (teks dibacakan) lewat tombol 🎵.
